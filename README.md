# Mobile Class SENAI

Repositório com projetos, exercícios e aplicações mobile desenvolvidas durante as aulas de Desenvolvimento Mobile do SENAI.

Este repositório reúne desde os primeiros exercícios de JavaScript e React Native até projetos mais completos com consumo de APIs, navegação entre telas, persistência de dados, integração com serviços externos e geração de builds com Expo/EAS.

## Sobre o repositório

O objetivo deste repositório é organizar os projetos desenvolvidos ao longo das aulas de mobile, servindo como histórico de evolução, estudo e prática dos principais conceitos utilizados no desenvolvimento de aplicativos.

Aqui estão reunidos projetos com diferentes níveis de complexidade, incluindo:

- exercícios iniciais de lógica e componentes;
- aplicações com React Native;
- projetos com Expo;
- consumo de APIs externas;

- persistência local;
- uso de SQLite;
- integração com Supabase;
- organização de componentes;
- estilização mobile;
- projetos com builds Android;
- uso de submódulos Git.

## Submódulos Git

O repositório possui o arquivo `.gitmodules`, indicando que alguns projetos são usados como submódulos.

Submódulos são repositórios Git dentro de outro repositório Git. Eles são úteis quando um projeto precisa manter outro projeto separado, mas ainda referenciado dentro da estrutura principal.

Projetos com indicação de submódulo:

```bash
consume-brasil-api
consume-brasil-api-mobile
```

Ao clonar o repositório, use:

```bash
git clone --recurse-submodules https://github.com/miguelzack/mobile-class-senai.git
```

Caso já tenha clonado sem os submódulos:

```bash
git submodule update --init --recursive
```

## Como executar os projetos

Como este repositório possui vários projetos separados, entre na pasta do projeto desejado antes de instalar as dependências.

Exemplo:

```bash
cd senai-cursos
npm install
npm start
```

Ou, dependendo do projeto:

```bash
npx expo start
```

Para executar no Android:

```bash
npm run android
```

Ou:

```bash
npx expo run:android
```

Para executar no navegador, se o projeto permitir:

```bash
npm run web
```

## Build com EAS

Alguns projetos possuem configuração para build com Expo Application Services, como `senai-cursos` e `cinewatch-app`.

Para gerar um APK de preview, entre na pasta do projeto e rode:

```bash
eas build -p android --profile preview
```

Ou, caso exista um perfil específico no `eas.json`:

```bash
eas build -p android --profile release-apk
```

Para verificar os perfis disponíveis:

```bash
cat eas.json
```

## Variáveis de ambiente

Alguns projetos podem possuir arquivo `.env`, principalmente aqueles que usam serviços externos como Supabase ou APIs.

Exemplo de variáveis que podem existir:

```env
SUPABASE_URL=
SUPABASE_ANON_KEY=
API_URL=
```

Por segurança, arquivos `.env` reais não devem ser enviados para o GitHub.

O ideal é manter um arquivo de exemplo:

```bash
.env.example
```

Exemplo:

```env
SUPABASE_URL=coloque_sua_url_aqui
SUPABASE_ANON_KEY=coloque_sua_chave_aqui
API_URL=http://localhost:3000
```
